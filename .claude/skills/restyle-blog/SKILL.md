# 真人风格改写（restyle-blog）

把 AI 整理的文章改写成真人博客的腔调。先按 §1 流程定体，再按 §2 风格档案动笔；每个风格档案自带原文样例和出处，仿写前先读样例。

## 1. 改写流程

按顺序执行，每步达标才进下一步：

1. **定体**：读原文，按 §2 映射表选目标风格；混合使用时记下哪段用哪种。师生对话实录（CKA 系列等）是成熟文体，不在本 skill 范围，直接告知用户不改。完成标准：风格名已确定。
2. **提事实核**：把原文的数字、命令、输出、链接、人名、时间、版本号逐条列成清单。完成标准：覆盖原文全部事实，一条不漏。
3. **重写**：按所选风格的规则逐条对照写。术语给一句字面定义；比喻全文最多留一个，只用于最难讲清的机制；条目长短允许不齐；对冲词只保留真不确定的，并写明为什么不确定。完成标准：风格规则逐条核过。
4. **保真**：逐条核对事实核清单，每条在改写稿里原样在场；删掉的注明原因。完成标准：清单全勾。
5. **自检**：`de-ai-writing` skill 在场就跑它的清单；不在场按这三项自检——黑名单词零命中、任意连续三段句式不雷同、事实核全勾。完成标准：三项全过。

始终保留原样：frontmatter、系列导航与「第 N/M 篇」计数、真实命令与输出（逐字）、原文链接。交付方式：直接改原文件，git 历史留底。

## 2. 风格档案与映射

| 文章体裁 | 风格 |
|---|---|
| 学习笔记、踩坑记录、实验报告 | Julia 体为主，概念讲解处借阮体 |
| 简报单条（News、工具推荐） | Simon 体为主，重点条目用阮体展开 |
| 概念科普、周刊 | 阮体 |
| 观点长文、年终总结 | 陈皓体 |
| 师生对话实录 | 已是成熟文体，不套用 |

### 阮一峰体（科普 / 周刊）

1. 第一句给事实或动作：谁做了什么
2. 机制一句说清就停，术语给字面定义
3. 每篇至少一个直评判断，用大白话
4. 数字具体且核过：倍数、年份、克数、行数
5. 骨架可以固定，条目内用自己的话，长短不齐

原文样例（周刊第 413 期）：

> 说实话，这三个理由都是场面话，真正的理由只有一个：省钱。
> 它被别人替代，说实话，一点都不冤。

出处：https://www.ruanyifeng.com/blog/2026/09/weekly-issue-413.html

### Simon 体（链接评论）

1. 结构三件套：链接 + 原文关键句引用 + 一句自己的观察，五行以内收
2. 那句观察要么补事实、要么带态度；两者都无，这条就不写
3. 对冲词只用在真不确定处

原文样例：

> Google knew about these in July, but chose not to disclose them until the WSJ reached out, presumably based on a tip.

出处：https://simonwillison.net/2026/Sep/18/gemini-hacked-three-companies/

### Julia 体（学习记录）—— 本博客主力体裁

1. 第一人称；「没搞懂」「还没测过」当内容写，不当缺陷藏
2. 每个结论带真实数字或命令，最好前后对照（5 秒 → 0.05 秒式）
3. 过程按实际顺序写，包括走错的路
4. 讲完最后一个点就停

原文样例：

> I still don't know exactly what went wrong in the query plan, but my best guess is that it was some sort of accidentally quadratic thing.

出处：https://jvns.ca/blog/2026/07/17/learning-about-running-sqlite/

### 陈皓体（观点长文）

1. 观点用断言给出
2. 亲历故事支撑：人名、公司、场景细节俱全
3. 承认局限时圈定范围，泛对冲全删
4. 加粗只给全文最承重的句子

原文样例：

> 我的经历和眼界非常有限……必然是受我的眼界和经历所局限的。

出处：https://coolshell.cn/articles/17583.html

## 3. 对照示例（AX 简报片段）

改写前（`src/News` 原文）：

> 打个比方：单个 AI 智能体像一个能力不错的工人，但当你要盖一栋楼——让十几个工人分工、按顺序施工、出了问题返工——就需要一个"施工总调度"。AX 就是 Google 把自家用的"总调度"方案开源了出来……

改写后（阮体 + Simon 体混合）：

> Google 把自家的智能体编排器 AX 开源了（agentexecutor.io）。编排器就是管「谁先做、谁后做、失败了谁重试」的那层软件。过去 LangGraph、AutoGen 各搞一套互不兼容；Google 进场，这层有了标准化的可能。HN 两天 629 分、288 条评论，编排层社区确实等了很久。具体架构以官方仓库为准，我还没实际跑过。

变化：三个比喻删净、定义改字面、判断句落地、数字全保、诚实收尾。

## 4. 红线

- 事实核一条不丢、一条不编：原文没有的数字和结论，改写稿里同样没有
- 「行动建议」只在存在具体动作时保留（能照抄执行的命令、配置）
- 比喻配额：全文一个
