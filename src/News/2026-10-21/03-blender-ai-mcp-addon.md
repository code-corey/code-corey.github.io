# blender-ai-mcp-addon：Blender 的 AI 助手与 MCP 服务器插件（7 天 936 星）

> 📅 2026-10-15 | 🏷️ 值得研究的仓库 | ⭐ 936（7 天窗口）| Python
> 🔗 原文：https://github.com/LiCinCan/blender-ai-mcp-addon

## 是什么

一个把 AI 助手和 MCP 服务器直接塞进 Blender 的开源插件：支持可视化对话操作 3D 场景、内置场景操作工具集和多智能体工作流，可对接 OpenAI、ChatGPT、Claude、Gemini、Ollama、OpenCode 等多种模型后端，底层通过 Blender 官方 Python API（bpy）驱动。仓库 10 月 15 日创建，7 天内冲到 936 星，是本周 GitHub 上增速最快的 AI 工具类项目之一。

## 🔍 小白解读

### 先说几个词

- **Blender**：全球最流行的免费开源 3D 创作软件，做三维建模、动画、特效都用它，游戏、影视、建筑行业大量使用。
- **MCP（Model Context Protocol）**：一个开放协议，让 AI 模型能以标准方式连接外部工具和数据，像"AI 世界的 USB 接口"——不管什么模型，插上就能操作你的软件。
- **bpy（Blender Python API）**：Blender 官方提供的 Python 编程接口，可以写脚本自动完成建模、渲染等操作，是这个插件驱动 3D 场景的底层通道。
- **多智能体工作流（Multi-agent Workflow）**：让多个各司其职的 AI 智能体协作，比如一个负责建模、一个负责材质、一个负责检查效果。
- **视觉对话**：AI 能"看懂"当前 3D 视口里有什么，你在对话中指着场景说"把球体变大一点"，它知道是哪个物体。

### 这篇到底在说什么

打个比方：以前用 Blender 做 3D 就像开手动挡的车，每个操作都要自己踩离合打方向——学习曲线陡，专业门槛高。这个插件等于给车装了个"AI 副驾驶"：你说"帮我搭一个客厅场景，暖色灯光"，它通过 MCP 协议调用 Blender 的接口去建模型、摆家具、打灯光，你还能在对话框里直接指挥调整。仓库 7 天拿 936 星，说明"用自然语言驱动 3D 创作"确实戳中了大量用户。值得注意的是它支持 Ollama 等本地模型——不花钱、不联网也能用，这个兼容清单（OpenAI/Claude/Gemini/Ollama 全覆盖）也是它能快速铺开用户的原因之一。

### 这跟普通人有什么关系

不会建模的普通人可以用说话的方式做 3D 内容了——游戏素材、产品展示、短视频里的 3D 元素，门槛从"学半年软件"降到"会打字描述"。对 3D 从业者，重复性的场景搭建、批量调整可以交给 AI，自己专注创意部分。

## 为什么值得架构师关注

- **MCP 生态从开发工具向桌面创作软件扩散的标志性样本**：此前 MCP 落地集中在 IDE、终端等开发者场景，进入 Blender 这类内容创作软件意味着"AI 操作 GUI 专业软件"的模式开始复制，企业内部工具 AI 化可以参考这套插件架构。
- **多后端适配的工程取舍**：同时兼容多家云模型与本地 Ollama，其抽象层设计（协议适配、能力降级、鉴权）对构建企业级 MCP 集成有直接参考价值。
- **自动化的风险面**：AI 直接驱动生产软件的脚本接口（bpy 权限很大），在受控环境外使用存在误操作与提示注入的暴露面，企业采用时需要沙箱与操作审计。
