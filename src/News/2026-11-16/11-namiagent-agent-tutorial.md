# NamiAgent：零基础手写 AI Agent 的中文开源教程（也是能在本地跑起来的 Agent）

> 📅 2026-11-16 | 🏷️ 国内生态 | ⭐ 529⭐（30 天慢热发现，创建于 2026-10-30，Python）
> 🔗 原文：https://github.com/aa1143/NamiAgent

> ℹ️ 编辑注：今日 Google News 中文源抓取为空，本条为 GitHub 数据中「中文圈技术项目」补位。

## 是什么

NamiAgent 是国内开发者开源的中文 AI Agent 教学项目，核心理念：Agent 没什么神秘的，核心就是一个 while 循环——调模型、执行工具、把结果写回上下文，再调模型。项目从 100 行的最小循环起步，用 11 节课逐课增加能力（工具系统、权限、上下文管理、Skills、MCP、子 Agent、计划、长期记忆），每一课都是可直接运行的完整代码快照；最后用三部分文章拆解 Claude Code、Codex、Pi、Grok Bot、DeepSeek Harness 等主流 Agent 的工程实现。它同时也是个能用的本地 Agent：带网页端可视化每一步思考和上下文变化，写文件/跑命令前弹窗确认。

## 🔍 小白解读

### 先说几个词

- **Agent（智能体）**：能让大模型不只是「聊天」，还能自己动手用工具（读写文件、执行命令）完成多步任务的程序。打个比方：聊天模型是顾问，Agent 是拿着工具箱干活的师傅。
- **MCP（Model Context Protocol）**：一套让 Agent 接入外部工具/数据源的标准协议，相当于给 AI 定义的「USB 接口」。
- **上下文管理**：控制发给模型的「对话记录」长度与质量的机制（截断、清理、摘要），是 Agent 能长时工作的关键。
- **长期记忆**：让 Agent 在新对话里还记得你是谁、之前做过什么，通常以文件或数据库形式存在。

### 这篇到底在说什么

现在市面上的 Agent 教程大多教你怎么「用」，NamiAgent 教你怎么「造」——而且造的过程只有 100 行代码起步。打个比方：别人给你一辆自动驾驶的车，这个项目拆开引擎盖，带你从轮子开始自己装一辆，装完你还能开着它干活。每学一课就多一个零件：第一课是最小循环，第二课加工具系统，第三课加权限确认（它要删文件时先问你），然后是上下文管理、技能加载、接 Telegram、定时任务、MCP、子 Agent、计划模式、长期记忆——到第 11 课已经是一个功能完整的本地 Agent。最有价值的部分是第三部分：把 Claude Code、Codex 这些明星产品按同样框架拆解给你看，「原来它们也就是这套循环加了这些机制」。项目用中文写成，只依赖 openai 一个包、默认接 DeepSeek，测试用假模型不需要 API Key，对中文初学者门槛极低。

### 这跟普通人有什么关系

如果你想转行 AI 工程或在自己的业务里搭 Agent，这是目前少有的高质量中文「从零造 Agent」路径——不需要先啃英文文档，不需要花 API 费用做练习（测试用假模型）。学完你对「Agent 到底怎么工作」的理解会超过大多数只会调框架 API 的人。

## 为什么值得架构师关注

- **团队内训教材候选**：与其让工程师从 LangChain 等框架的抽象开始，NamiAgent 这种「最小循环 + 逐层加机制」的路径能快速建立对 Agent 本质的判断力，避免框架锁定（项目自身就刻意只用 openai 一个依赖）。
- **生产 Agent 的机制清单**：11 课的目录本身就是一份「生产级 Agent 需要哪些机制」的 checklist——权限分级确认、上下文截断/摘要、计划模式由代码强制只读、记忆逐条确认入库，每一项都对应真实工程问题，可作为内部 Agent 平台的评审参照。
- **中文生态信号**：529 星/17 天的增速说明中文「原理级」Agent 教学存在真实需求缺口；做开发者产品/内容的团队可参考其「每课可运行快照 + 可视化网页端」的内容设计模式。

## 核心内容

- 结构：11 课代码（lesson-01 至 lesson-11，每课完整可运行快照）+ 拆解文章（Claude Code、Codex、Pi、Grok Bot、DeepSeek Harness、OpenClaw 等）。
- 课程路径：最小 while 循环 → 工具注册表/统一执行器 → 权限（硬规则→风险分级→人工确认）→ 上下文管理（截断→清理→摘要+会话持久化）→ Skills（AGENTS.md 常驻+按需加载）→ 接入 Telegram → 定时任务与心跳 → MCP stdio 客户端 → 子 Agent 与多 Agent（独立上下文、并行只读）→ 计划（代码强制只读模式）→ 长期记忆（每条确认、会话检索）。
- 工程约束：只依赖 openai 单包；OpenAI 兼容接口默认接 DeepSeek，换模型只改两个环境变量；测试用假模型免 API Key（第 11 课共 49 个测试）；写文件/执行命令前弹窗确认。
- 配套：本地网页端（`python web/app.py`）可视化每步思考、工具调用与完整上下文；图文教程站 namiai.tech；MIT 代码许可 + CC BY-NC 文档许可。
- 作者另有前置项目 NamiGPT（理解模型本身），与本项目构成「模型→模型外那一圈」的学习路径。

## 行动建议

评估试用：适合作为团队新人的 Agent 入门教材，按「先跑通 lesson-01 → 精读权限与上下文两课 → 对照拆解篇读 Claude Code」的顺序推进；如果你正选型 Agent 框架，先花两天手写一遍这个项目再决定，对框架的能力边界会有完全不同的判断。资深团队可直接把第 10/11 课的「计划只读强制」「记忆逐条确认」机制移植进内部 Agent。
