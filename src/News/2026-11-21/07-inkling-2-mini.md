# Introducing Inkling 2 Mini（Thinking Machines 发布笔记本可跑的循环推理小模型，开源权重）

> 📅 2026-11-20 | 🏷️ 模型发布 & 行业动态 | ⭐ HN 590 分 / 96 评论 + HF 549 likes
> 🔗 原文：https://thinkingmachines.ai/news/inkling-2-mini/
> 💬 讨论：https://news.ycombinator.com/item?id=50581260

## 是什么

Thinking Machines Lab（Mira Murati 创办的 AI 公司）发布 **Inkling 2 Mini**：一个「快、强、小到能在笔记本上跑」的开源权重模型。它的核心创新是**循环 Transformer（looped transformer）**——把模型的中间层对每个 token 重复跑三遍，相当于「多转几圈再作答」，用更少的输出 token 达到更强的推理质量。官方基准显示其在 DeepSWE v1.1（48.2%）与 Vals Index v2.2（46.5%）等基准上**领先所有总参数量小于 100B 的开源权重模型**，且运行速度更快。本文与 11 月初发布的同系 Inkling 2 Small 属同一产品线，本次为新的 Mini 档发布。

## 🔍 小白解读

### 先说几个词

- **循环 Transformer（Looped）**：普通模型从头到尾过一遍网络就吐出答案，循环模型把中间几层反复跑多次。打个比方：别人草稿打一遍就交卷，它把草稿在脑子里默算三遍再写。
- **MoE（混合专家）**：模型总参数很大，但每个 token 只激活一小部分「专家」，兼顾容量与速度。
- **NVFP4 量化**：用 4-bit 精度存储权重（原生的，不是事后压缩），模型体积和显存占用大幅缩小。
- **开源权重**：模型参数文件公开可下载（HuggingFace 上已有官方权重与社区 GGUF 量化版），可以本地部署、微调、商用（具体许可看模型卡）。
- **CoT 可监控性（Monitorability）**：通过读模型的思维链来监督它在想什么。循环推理会把思考「藏」在循环里而不是写出来，这正是官方重点研究的安全性课题。

### 这篇到底在说什么

小模型通常打不过大模型，因为它「想」得浅。Inkling 2 Mini 的思路是：不给模型加参数，而是给它加「思考时间」——同样的中间层反复跑三圈，每多一圈就多一轮推理打磨。结果是一个总参数 26.4B、每 token 只激活 3.4B 的小家伙，在编程与推理基准上赢了所有 100B 以下的开源模型，而且因为循环并不增加写出 token 的长度，实际生成速度还更快。整个模型原生用 4-bit 精度训练和部署，总占用约 20GB，官方演示它在一台 MacBook Pro 上离线跑、几分钟内写出一个可玩的飞行模拟器。配套发布的还有一个可变循环次数的研究版，数据显示：循环从 1 次加到 3 次，模型的「无思维链任务时长」从 16 秒提升到 37 秒；循环加到训练时的两倍（10 圈）性能仍在涨，且思维链始终保持可读、破坏性行为未上升。**和上一代/竞品比强在哪**：同级开源模型里的编码基准第一；**开源还是闭源**：开源权重（HF 可下载，unsloth 已出 GGUF）；**要换模型吗**：本地/端侧 Agent 编码场景强烈建议评估。

### 这跟普通人有什么关系

不用花钱买云 API，一台普通游戏本就能跑一个编码能力同级最强的模型——离线可用、数据不出机器、没有按 token 计费。对写代码的人来说，这是「随身 AI 工程师」的一大步。

## 为什么值得架构师关注

1. **端侧/本地推理选型池更新**：约 20GB 权重 + NVFP4 原生 + GGUF 生态，可进入本地开发助手、离线 Agent、隐私敏感场景的候选池，替代部分云端 API 调用。
2. **「推理时计算」新增一个维度**：除了 chain-of-thought 与测试时搜索，循环深度成为可调节的算力-质量旋钮（且官方数据显示泛化到训练 2 倍的循环数）——自建推理系统可探索把循环深度做成按请求的服务等级参数。
3. **监控性与合规权衡**：循环推理把推理过程压缩进循环而非文本 CoT，官方已专门研究其可监控性（CoT 保持可读、sabotage 指标未上升），但采用前仍应把「思维链监控」纳入你的安全评估清单。
4. **成本模型**：3.4B 激活的 MoE 在消费级硬件上的 tokens/s 表现，可能显著低于同级稠密模型的单 token 成本——做 TCO 对比时按「每任务成本」而非「每 token 成本」计算。

## 核心内容

- 架构：循环 Transformer，中间层每 token 重复 3 次；MoE 总参 26.4B、激活 3.4B、计循环后每 token 权重激活 5.4B。
- 基准：开源权重 <100B 总参模型中，DeepSWE v1.1 48.2%、Vals Index v2.2 46.5% 领先；对比对象含 Qwen3.8-27B、Gemma 4 26B A4B 等（官方基准图）。
- 部署：权重主体原生 NVFP4（末 4 层 MXFP8），总占用约 20GB，官方演示 MacBook Pro 离线运行。
- 配套研究：发布可变循环研究版——无 CoT 时间跨度 1 圈 16s → 3 圈 37s；性能持续提升至 10 圈（训练的 2 倍）；思维链随循环增加变短但保持可读；agentic sabotage 测试未随循环数上升。
- 获取：官方权重在 HuggingFace（HF 549 likes），unsloth 已发布 GGUF 量化版；可通过 Tinker 平台试用。HN 590 分 / 96 评论。

## 行动建议

- **要不要更新选型**：本地 Agent 编码、离线工具、隐私敏感场景——本周下载 GGUF 在目标硬件上实测编码任务通过与 tokens/s；云端 API 为主的团队将其列入「降本备选」观察名单即可。
- **评估要点**：在你自己的代码库上对比 Qwen3.8-27B 级模型的任务完成率；确认所用推理引擎对循环架构与 NVFP4 的支持情况。
- **安全团队**：审查循环推理对你们 CoT 监控管线的兼容性（监控的是「写出来的思考」，循环推理写的更短）。
