## 是什么

据东方财富报道，DeepSeek 与 MiniMax 同期在**智能体（Agent）赛道**出招，国产大模型竞争的主战场正从「拼跑分的基础模型」转向「拼任务完成度的智能体」；同日另一则财经报道显示，MiniMax 上新产品定价较此前直降七成。能力战与价格战同时开打，国内团队的模型选型与成本模型都在被改写。

## 🔍 小白解读

### 先说几个词

- **智能体（Agent）**：不只回答问题、还能自己拆解任务、调用工具、多步执行的 AI。打个比方：聊天模型是「顾问」，你说它答；智能体是「助理」，你说个目标它自己跑腿办完。
- **智能体之战（新战场）**：厂商竞争焦点从「考试分数」转向「能不能替你把活干成」。跑分像笔试，agent 能力像上岗实操。
- **价格降七成**：同类能力的单价降到原来的三成左右。打个比方：头等舱服务直接按经济舱价格卖——受益的是所有做 AI 应用的团队。
- **国产模型（DeepSeek/Qwen/Kimi/GLM/MiniMax）**：中国厂商的大模型梯队，特点是开源生态活跃、价格竞争激烈、迭代速度快。
- **成本结构（Cost Structure）**：跑一个 AI 功能每个请求花多少钱。agent 应用是「多步循环」型消耗大户，单价降七成对它的账本影响是乘法级的。

### 这篇到底在说什么

打个比方：去年的国产大模型竞争像「高考放榜」，大家比谁的分数高；今年风向变了，变成「招聘实操考核」——谁能真的替用户把复杂任务从头到尾办完，谁才有商业价值。报道说 DeepSeek 和 MiniMax 都在这个新战场上出了牌：一个带着工程效率和开源口碑继续深挖，一个直接把新产品价格打到三折。为什么敢降？因为 agent 时代的商业模式变了——单价低，用量才能起飞；用量起飞，总收入反而更高。对中国百万级开发者来说，这是双重利好：能干活的智能体模型 + 打三折的价格，意味着去年预算做不起的 agent 应用，今年可以立项了。资本市场同日给出反应，多只概念股三季度业绩预喜。

### 这跟普通人有什么关系

你用的国产 AI 助手会越来越像「能干活的助理」而不是「聊天对象」：订机票、做报表、盯数据这类多步骤任务正在成为标配。而价格战最终由用户受益——无论是 C 端会员费还是 B 端服务报价，都有下探空间。

## 为什么值得架构师关注

- **选型权重迁移**：模型评估从静态 benchmark 转向 agent 任务完成率（工具调用成功率、多步规划稳定性），评测集需要重建。
- **成本模型重算**：MiniMax 降价七成直接改写 agent 应用的单位经济模型——此前因成本砍掉的多步 agent 功能值得重新测算 ROI。
- **国产栈可行性提升**：DeepSeek + MiniMax 的组合意味着「全国产技术栈跑生产级 agent」的采购方案成立性增强，对合规敏感行业是实质利好。
- **锁定风险提示**：价格战红利期选择深度绑定单一厂商的私有协议，未来议价能力会被反噬，接口抽象层要坚持做。

## 核心内容

- DeepSeek 与 MiniMax 同期在智能体赛道出手，国产模型竞争焦点转向 agent 能力（东方财富）。
- MiniMax 新产品定价较此前下降约七成，价格战与能力战并行（同日东方财富财经报道）。
- 多只 AI 概念股三季度业绩预喜，商业化兑现开始体现在财报层面。
- 国内大模型周调用量持续增长的行业背景（当日另有多条财经源报道调用量数据），为价格战提供量能支撑。

## 行动建议

- 选型团队：把「智能体任务完成率」加入国产模型评测矩阵，用真实业务任务（而非通用考卷）做横向对比。
- 成本敏感团队：重算 agent 功能的单位经济账，降价七成足以让一批「预算否决」项目复活。
- 采购策略：趁价格战窗口签订灵活条款（按量阶梯、可切换），避免在低谷期锁定长期高价合约。
