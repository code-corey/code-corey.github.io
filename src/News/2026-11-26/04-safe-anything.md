# safe-anything：100% Rust 快速漏洞扫描器，连 AI agent 配置也扫

> 📅 2026-11-22（创建） | 🏷️ 值得研究的仓库 | ⭐ 704（7天爆发窗口，Rust）
> 🔗 原文：https://github.com/erkamyaman/safe-anything

## 是什么

一个 100% Rust 编写的快速漏洞扫描器，口号是「在别人之前找到洞」：一次扫描覆盖 XSS、SQL 注入、泄露的密钥、依赖 CVE，以及——最有差异化的一点——**AI agent 的配置**。项目创建于 11 月 22 日，4 天即获 704 星。

## 🔍 小白解读

### 先说几个词

- **XSS（跨站脚本）**：攻击者把恶意代码塞进网页，其他用户浏览时中招。好比在公告栏贴一张看似正常、实际带机关的通知。
- **SQL 注入**：攻击者在输入框里夹带数据库命令，骗系统执行。好比在快递单备注栏里夹一张「把仓库钥匙给我」的纸条。
- **泄露密钥**：把 API Key、数据库密码硬编码在代码里并上传到仓库，等于把家门钥匙贴在小区公告栏。
- **CVE**：公开记录的软件漏洞编号清单。你用的每个开源库都可能有已知漏洞，扫一遍就知道有没有中招。
- **AI agent 配置**：给智能体（agent）的权限设定——它能访问哪些文件、调用哪些工具、花多少钱。配置过宽等于给实习生一张无限额度的公司信用卡。

### 这篇到底在说什么

安全扫描工具不少见，这个仓库特别的地方有两点。第一，它是纯 Rust 写的，主打一个「快」——大代码库全量扫描时速度就是生产力。第二，也是它 4 天冲到 704 星的原因：**它把 AI agent 的配置也当成攻击面来扫**。打个比方：传统扫描器检查的是「门锁结不结实」（代码漏洞），这个工具还会检查「你有没有把仓库备用钥匙随手给了一个临时工」（agent 权限配置）。随着越来越多公司让 AI agent 接入代码库、云账号和支付接口，agent 配置错误正在成为新的重大安全隐患，把它纳入常规扫描是对趋势的精准卡位。

### 这跟普通人有什么关系

对小团队来说，多了一个免费的自查工具：上线前扫一遍代码，至少能拦住「密钥传上 GitHub」这种低级但致命的事故。对用 AI 编程助手的开发者，它可以帮你检查给 agent 的权限是不是开太大了——这类配置错误一旦被利用，损失的是整个云账号。

## 为什么值得架构师关注

- **新攻击面建模**：「AI agent 配置」作为扫描对象意味着安全左移清单的扩容——agent 工具权限、支出上限、可访问资源都应纳入安全审计范围。
- **CI 集成评估**：Rust 实现的扫描速度适合流水线高频运行，可作为现有 SAST/SCA 工具的补充或替代候选做对比测试。
- **供应链安全**：依赖 CVE 扫描 + 密钥检测 + 注入类检查一体化，减少工具链拼装成本。

## 核心内容

- **五类检查合一**：XSS、SQL 注入、泄露密钥、依赖 CVE、AI agent 配置。
- **100% Rust 实现**，定位快速扫描。
- 创建于 2026-11-22，4 天 704 星，属于 7 天爆发窗口的高增速项目。
- 把 agent 配置纳入扫描是与其他开源扫描器的核心差异点。

## 行动建议

- 在测试分支上试跑，与现有 SAST/密钥扫描工具对比**检出率与误报率**。
- 重点审阅其「AI agent 配置」检查规则的覆盖面与判定逻辑，规则质量决定工具价值。
- 注意项目非常年轻（<1 周），生产引入前评估维护活跃度与社区反馈，勿直接替代成熟工具。
