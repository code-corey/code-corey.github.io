# Aurelio Finance：开源本地优先的 AI 记账理财应用

> 📅 2026-10-10 | 🏷️ 值得研究的仓库 | ⭐ GitHub ⭐1554（7天爆发）
> 🔗 原文：https://github.com/LosaLosSantos/aurelio-finance

## 是什么

Aurelio 是一个开源的个人财富管理与理财规划应用，跑在你自己的电脑上，数据存在本地文件里，并内置一个可以对话的 AI 财务顾问。项目用 Python（后端）加 Node.js 编写，2026-10-06 创建，7 天冲到 1554 星。

## 🔍 小白解读

### 先说几个词

- **本地优先（local-first）**：你的数据主要存在自己电脑上，而不是先传到某家公司的服务器。打个比方：账本锁在自己家抽屉里，而不是存在别人家。
- **净值**：你拥有的（存款、股票、房产等）减去你欠的（贷款等），也就是"真正属于你的钱"。
- **ETF**：一种像股票一样可以买卖的基金，一买就等于打包买了一篮子股票。
- **AI 财务顾问**：一个能跟你聊天、根据你的账本数据回答问题和提建议的 AI 助手。
- **开源**：代码全部公开，任何人都可以查看、下载、自己部署。

### 这篇到底在说什么

这是一套完整跑在本机的个人财务管理应用：追踪银行和券商账户的现金、按日期记录持仓状况，你的每一笔投资按市场价算出成本、收益和分红，还能看基金"穿透"后实际持有的国家、行业和公司，以及经常性投资、房产和贷款。现金流部分覆盖收支、储蓄率和每个目标需要的回报率。AI 顾问叫"Ask Aurelio"，它只根据你自己的账本记录回答问题，可以联网搜索，并且每一条修改建议都以卡片形式让你确认或拒绝。关键是 AI 部分是可选的：用你自己的 OpenRouter API Key 接入，不想用 AI 就纯当记账工具。数据存在本地的 `backend/data.db` 文件里，升级前应用还会自动备份一份副本。项目 2026-10-06 才创建，7 天拿下 1554 星，还提供了 `--demo` 模式，用虚构数据先体验再决定要不要录入真实账本。

### 这跟普通人有什么关系

记账理财最担心的就是"我的全部家底数据交给了谁"。这类本地优先应用给出另一种选择：数据不出电脑，AI 顾问照样能用。如果你懂一点技术，可以自己部署一套试试；不懂技术也没关系，"本地优先 + 可选 AI"这个思路正在变成消费级 AI 产品的一个重要方向，值得留意。

## 为什么值得架构师关注

这是隐私敏感场景（财务/健康）做 AI 功能的代表性参考架构：本地优先存储作为数据主权边界，AI 只通过用户自有的模型 API Key 拿到上下文，且是可选项——不接 AI 产品依然完整可用。工程上有几个值得借鉴的决策：每条 AI 建议以"待确认卡片"呈现、由用户确认或拒绝（把 LLM 输出定位在建议而非自动执行）；数据文件在格式变更前自动快照备份；`--demo` 模式用虚构数据降低试用门槛。技术栈是 Python 后端 + Node.js，自部署门槛低，适合做架构研究与二次开发。风险点：LLM 在投资话题上的幻觉性建议如何防护，需要看其提示词与确认机制的实际效果；依赖单一本地 SQLite 文件，多人/多设备场景能力有限。

## 核心内容

- 功能覆盖净值与账户、投资持仓（成本/收益/分红）、基金穿透分析（国家/行业/公司/货币）、计划与房贷负债、现金流与储蓄率及目标回报测算。
- AI 财务顾问"Ask Aurelio"基于用户自己的账本记录回答，可联网搜索，所有修改以卡片形式交用户确认或拒绝。
- 本地优先：数据存于本机 `backend/data.db`，更新改变格式前自动保存副本；AI 为可选项，通过 OpenRouter 使用用户自己的 API Key，默认模型为 Claude Opus 5.5（每百万输入 token 4 美元、输出 20 美元，README 注明为 2026 年 10 月实测）。
- 支持 macOS / Linux / Windows 一键启动，并提供 `--demo` 虚构数据体验模式。
- 2026-10-06 创建，7 天 1554 星，README 附 CI 徽章与《How Aurelio reasons》设计文档。

## 行动建议

- 个人可先用 `--demo` 模式体验，再决定是否录入真实数据自托管试用，重点体验 AI 顾问回答的质量。
- 做 C 端 AI 功能的团队可研究其隐私边界设计：本地存储、自有 API Key、建议需确认这三层如何组合。
- 评估引入时重点看两点：数据导出格式是否开放（避免被锁死）、AI 顾问对投资建议是否有防幻觉与免责设计。
