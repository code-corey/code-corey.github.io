# aave-oracle-lag-arb: Aave V3 oracle-lag arbitrage（预言机滞后套利工具：币安事件催生的完整开源实现）

> 📅 2026-10-31 | 🏷️ Web3 & Crypto | ⭐ 38 Stars（创建于 2026-10-30，7 天窗口；小仓库，但问题独特、工程完整）| 语言：TypeScript + Solidity
> 🔗 原文：https://github.com/akari-sora/aave-oracle-lag-arb

## 是什么

一个在币安失窃案（10-29）次日诞生的开源项目，把事件中真实发生的「预言机滞后套利」做成了完整工具链：Solidity 套利合约（OracleLagArb）+ 盯盘机器人（覆盖以太坊、Arbitrum、Base、Optimism，逐块监控）+ Linux 常驻守护 + 可供 Claude Code/Codex 等 Agent 安装托管的技术能。README 还原了案例数据：事件期间 ETH 在 Uniswap 一度较其他市场溢价 10%~30%，最赚钱的地址据此获利约 347 万美元。

## 🔍 小白解读

### 先说几个词

- **预言机（Oracle）**：把链外价格「喂」给链上协议的数据管道。Aave 用 Chainlink 的 ETH 价格来决定「你的抵押品值多少钱、能借多少」。
- **预言机滞后套利（Oracle-lag arb）**：当市场真实价格剧烈波动、而预言机价格「反应慢半拍」时，按预言机的旧价格借出资产、再到真实价格更高的地方卖掉，赚取差价——本质是「信息时差」套利。
- **闪兑/闪电贷式交易（Flash-swap）**：一笔链上交易内完成「借—卖—再买—还」，原子化执行，任何一步不满足条件就整体回滚，不留下裸露风险敞口。
- **健康因子（Health factor）**：借贷协议里的「安全仪表」——低于 1 就会被清算。机器人会在此指标恶化时自动降杠杆。
- **Agent 技能（Agent skill）**：写给 AI 编码代理的操作手册，让 Claude Code/Codex 这类 Agent 能自动部署、监控这套系统——「AI 运维 DeFi」的新形态。

### 这篇到底在说什么

打个比方：10 月 29 日币安热钱包被盗、暂停提币（前两期简报已跟踪），大量 ETH 被困在币安出不来，于是 Uniswap 上的 ETH 被买得比别处贵 10%~30%。而 Aave 的定价来源 Chainlink 预言机「慢半拍」，仍按便宜的旧价格放贷。有玩家发现了这个时差：把稳定币存进 Aave → 按旧价格借出便宜的 ETH → 拿到 Uniswap 按高价卖掉 → 换回稳定币再存入 → 循环往复；等两边价格靠拢后再低价买回 ETH 还债，落袋为安。据 README 引用的链上数据（0xNaiXi/Chaincatcher 报道），获利最多的地址以约 2,580 美元卖出 12,289 枚 ETH、再以约 2,297 美元买回，赚了约 347 万美元。这个仓库把整套打法工程化：合约把「存—借—卖」打包成一笔原子交易并内置链上最低卖价校验；机器人逐块盯四个链上的价差，只在溢价持续时开仓、价差收敛时平仓、健康因子恶化时自动降杠杆；还配了服务器守护脚本和 webhook 告警。作者同时明确警示：这是带杠杆的做空 ETH 仓位，不是无风险套利——若 ETH 大涨照样会被清算，Aave 也可以随时冻结市场。

### 这跟普通人有什么关系

对普通 DeFi 用户：你的存款/借款协议的「价格来源」可能落后于真实市场，极端行情下这既是风险（抵押定价失真）也是别人的利润来源。对持币观望者：这类案例说明交易所级黑天鹅会通过流动性错位传导到借贷协议——资产分散、杠杆别满，是普通人的直接启示。对开发者：这是一个「安全事件 → 开源工具诞生」只用一天的样本，AI 辅助开发让事件驱动型工具的生产周期大幅缩短。

## 为什么值得架构师关注

- **预言机风险的一手复盘样本**：单一价格源滞后在极端行情下会被系统性套利，多源喂价、变化率熔断、异常带宽限制等防御设计可对照本案例自查。
- **原子化风控设计参考**：合约层把「最低卖价校验」写进交易原子性，机器人层把「健康因子自动降杠杆」做成闭环——分层风控（合约内硬约束 + 链下软策略）是 DeFi 工程的标准答案模板。
- **AI 运维基础设施的雏形**：为 Claude Code/Codex/Hermes/Grok Bot 提供 Agent 技能，指向「AI 代理 7×24 托管策略执行」的工程形态，值得评估其权限边界设计。
- **事件驱动开发的加速信号**：从黑天鹅发生到完整开源工具链只隔一天，说明「事件 → 工具」的响应速度已成为可竞争的能力维度。

## 核心内容

- 背景数据：10-29 币安热钱包被盗、暂停提币后，ETH 在 Uniswap 一度较其他市场溢价 10%~30%；Aave 按 Chainlink 滞后价格持续放贷，形成套利窗口（README 引述）。
- 头部案例：最赚钱地址约 $2,580 卖出 12,289 ETH、约 $2,297 买回 12,314 ETH，获利约 347 万美元（0xNaiXi 数据，Chaincatcher 报道，README 引用）。
- 仓库组成：OracleLagArb Solidity 合约（单笔闪兑式完成存/借/卖，链上校验最低卖价）+ TypeScript 机器人（以太坊/Arbitrum/Base/Optimism 逐块监控，健康因子自动降杠杆）+ Linux 守护与 webhook 告警 + Agent 技能。
- 风险声明：带杠杆做空 ETH，非无风险套利；Aave 可随时冻结市场；演示 GIF 基于本地主网分叉模拟（模拟事件、压缩时间，非真实成交）。
