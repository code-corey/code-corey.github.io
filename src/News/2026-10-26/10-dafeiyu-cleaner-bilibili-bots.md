# dafeiyu-cleaner: DeepSeek 蓝色大肥鱼消除计划（清理 B 站评论区 DeepSeek 驱动机器人账号）

> 📅 2026-10-23 | 🏷️ 国内生态 | ⭐ ⭐89（7 天窗口，创建 3 天；低于百星特批：问题独特、代码可见）
> 🔗 原文：https://github.com/liyupi/dafeiyu-cleaner

## 是什么

一个针对 B 站（Bilibili）评论区的开源浏览器插件（支持 Chrome / Edge / Firefox），用于识别并清理由 DeepSeek 大模型与 AI Agent 驱动的机器人账号——作者称之为「大肥鱼」。技术上是「离线规则 + DeepSeek API 精判」的两级架构：本地规则先筛，API 对可疑账号做精确判定，支持 AI 评论检测、空间主页鉴定、一键清场。项目 10 月 23 日上线，3 天 89 星。虽然星数未过百，但其指向的现象与混合检测架构值得一看，特批入选本期国内生态。

## 🔍 小白解读

### 先说几个词

- **AI 机器人账号（Bot）**：由大模型自动生成评论、批量运营的账号。它们会说「人话」，比传统的「复制粘贴水军」更难辨认。
- **两级检测架构**：先用便宜的本地规则快速筛掉明显可疑的，再对剩下的疑难样本调用大模型精判——成本和准确率的折中方案。
- **离线规则**：写在代码里的判断条件（如昵称特征、评论文案模式），不联网就能跑，速度快、零成本。
- **浏览器插件**：装在浏览器里的增强小程序，可以修改你看到的网页，比如把疑似机器人的评论折叠掉。

### 这篇到底在说什么

打个比方：小区门口以前混进的是穿统一马甲的发传单的（传统水军），一眼就能认出来；现在混进来的是「会聊天的高级推销员」——每句话都不一样，还能接你的梗，这就是大模型加持的机器人账号。这个插件干的事，就是帮你在 B 站评论区把这类「大肥鱼」捞出来：先靠本地规则快速扫描（快、免费），拿不准的再请 DeepSeek 来当「鉴定师」看一眼（准、花小钱），最后给你一个一键清理的按钮。这个项目的走红背后是一个更大的中文互联网现象：开源大模型让「批量生成像人话」的成本趋近于零，评论区正在成为人机混居的场地，民间开始自造工具自保。

### 这跟普通人有什么关系

你在 B 站、微博、小红书看到的评论里，AI 生成的部分越来越多——被带节奏、被软广、被假「网友亲测」忽悠的风险在上升。这类工具让你拿回一部分「只看真人发言」的选择权。

## 为什么值得架构师关注

1. **中文互联网 AI 内容农场的民间信号**：当社区自发出现清理工具，说明平台侧治理滞后于滥用速度——做内容平台的团队应把「LLM 驱动的批量账号」列入威胁模型。
2. **「规则粗筛 + LLM 精判」是可复用的检测架构**：成本可控的混合判定模式，适用于风控、审核、反爬等多种场景，值得作为内部方案参考。
3. **攻防同源**：检测端用 DeepSeek 识别 DeepSeek 驱动的内容，提示模型指纹与行为特征分析会成为内容安全的新课题。
4. **生态位观察**：类似工具的流行会反向推动平台推出官方标记（AI 内容标签/账号认证），影响内容分发与合规策略。

## 核心内容

- 目标：识别并清理 B 站评论区中由 DeepSeek 大模型、AI Agent 驱动的机器人账号（「大肥鱼」）。
- 形态：Chrome / Edge / Firefox 浏览器插件，开源。
- 架构：离线规则初筛 + DeepSeek API 精判的两级检测；功能含 AI 评论检测、空间主页鉴定、鲸鱼娘一键清场。

- 背景：开源大模型大幅拉低批量生成「像人话」内容的成本，中文社区正自发出现对抗工具。
