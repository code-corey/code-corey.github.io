# Zero-Shot to New Robots: Introducing Dream-1（零样本上手新机器人：Dream-1 发布）

> 📅 2026-10-24 | 🏷️ 模型发布 & 行业动态 | ⭐ HN 179 分/77 评论
> 🔗 原文：https://dreamlabs.ai/research/dream-1/

## 是什么

Dream Labs 正式出 stealth，发布其首个世界动作模型（World Action Model, WAM）**Dream-1**，并同步宣布 9000 万美元种子轮融资。Dream-1 通过公开 API 提供，每小时 3 美元起：给一台它从没见过的双臂机器人接上 API，无需微调、无需该机器人的示范数据、无需机器学习专家，即可开箱执行任务。同期公布的还有机器人硬件价格曲线：像样的双臂机械臂套装已降到约 2000 美元。

## 🔍 小白解读

### 先说几个词

- **世界动作模型（WAM）**：不只「看懂」世界的模型（世界模型），还要能直接输出机器人的动作——从「理解画面」到「动手干活」。
- **零样本（Zero-shot）**：不用针对新设备做任何专门训练，拿来就用。类似一个通晓所有车型的老司机，换辆没开过的车也能直接上路。
- **本体（Embodiment）**：机器人圈的行话，指「一台具体的机器人身体」。每台机器人的臂长、关节、抓手都不同，传统方案要为每个身体单独训练。
- **Post-training（后训练）**：基座模型训好之后，用少量数据把它「掰」到具体任务上的环节。
- **冷启动问题**：机器人要好用就需要数据，数据又要等机器人被广泛使用才有——先有鸡还是先有蛋的僵局。

### 这篇到底在说什么

打个比方：以前的机器人像「定向培养的员工」——只在自家工厂的训练环境里学过，换个岗位就什么都不会；Dream-1 想做的是「通用老司机」：没见过这辆车也能开。故事的起点是团队 2026 年 2 月发布的 DreamZero 论文（首次提出世界动作模型范式）：当时他们发现，只用 30 分钟某型机器人的数据做后训练，模型就能把通用任务知识迁移过去并零样本泛化到没见过的任务——而以前这需要几百上千小时该机器人的专属数据。半年后，他们把它做成了公开 API。为什么是现在？因为硬件端同步降价：像样的双臂套装约 2000 美元，7 台半人形机器人不到 1.5 万美元，Hugging Face 399 美元的小机器人 Microduck 上架 4 天卖了上万台。便宜的硬件 + 会泛化的模型，机器人行业的「飞轮」第一次看起来转得动。

### 这跟普通人有什么关系

家用与小型商用机器人离实用又近了一步：价格进入消费品区间，能力开始「开箱即用」。对开小店的、做仓储的、想买机器人做家务的人，未来几年会看到「按小时付费的机器人智能」这种新选项。

## 为什么值得架构师关注

1. **具身智能正在复制 LLM 的商业结构**：基础模型 + API 计费（$3/小时）+ 硬件厂商生态，做机器人相关业务的团队要评估「自研策略模型」还有多少必要。
2. **比上代强在哪（官方口径）**：DreamZero 时代需要约 30 分钟本机数据做后训练才能迁移；Dream-1 迈向对未见机器人、未见任务、未见环境的完全零样本——数据门槛从「小时级」压到「零」。
3. **闭源 API 形态**：与 Kimi K3 等开源模型不同，Dream-1 仅通过 API 提供，供应商锁定与数据出境问题需在方案设计时考虑。
4. **成本模型可直接套算**：$3/小时对标人力成本，仓储、巡检、门店服务类场景可先算 ROI。

## 核心内容

- Dream-1 为世界动作模型（WAM）：控制未见过的机器人、执行未见过的任务，开箱即用；公开 API 定价 $3/小时。
- Dream Labs 同步出 stealth，宣布 9000 万美元种子轮融资；beta 客户覆盖 12 个站点。
- 技术源头：2026 年 2 月 DreamZero 论文提出 WAM 范式；仅用 30 分钟 YAM 机器人数据后训练即出现零样本泛化，远超以往数百上千小时本机数据的要求。
- 硬件背景：双臂机械臂套装约 $2,000；7 台半人形机器人合计低于 $15,000；Hugging Face $399 的 Microduck 上市 4 天售出 10,000+ 台（8 月末上市）。
- 论断：便宜硬件 × 可泛化模型 × 使用即产数据，机器人冷启动循环首次具备解冻条件。

## 行动建议

机器人/自动化相关团队：申请 API 试用，在真实工位上验证零样本能力的真实成色，并测算 $3/小时 模型下的人力替代账；关注其 SDK 与仿真环境降低试错成本。非机器人行业架构师：把「具身智能 API 化」列入 12 个月技术雷达，暂不需要行动。
