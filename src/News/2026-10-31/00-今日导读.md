## 🔥 今日架构师要闻三条

1. **Claude Code 扩展惊现供应链后门**：一个伪装官方的 Claude Code VS Code 扩展在 Cursor 插件市场带后门分发近 12 小时，植入持久化 SSH 后门，开发者机器的信任模型被正式击穿——今天请先审计团队插件清单。
2. **币安遭史上最大加密失窃**：约 63 亿美元资产被指向朝鲜的黑客组织盗走，币安暂停交易并承诺兜底，比特币跌破 77,000 美元——交易所托管风险与市场连锁反应同时引爆。

## 今日趋势总结

今天的两个世界被同一条主线贯穿：**安全与信任的重新定价**。AI 侧，攻击者从「攻击软件」转向「污染工具链本身」，插件市场、Agent 权限、开发机凭证全部进入攻击面清单；Web3 侧，史上最大失窃把「托管信任」的脆弱性摆上台面，链上取证与可验证性技术（ABF-Bench 正是样本）随之升温。第二条主线是**资本收紧**：Anthropic 评级隐忧与 OpenAI 融资目标下调，意味着依赖头部厂商的选型决策需要补上「供应商财务韧性」这一课。技术侧的小趋势是**端侧 Agent 加速**（dsh-Go 一周 2.4k 星、LFM3 全家桶）与**Agent 工程走向规范化**（可解释、可验证、可评测成为关键词）。
