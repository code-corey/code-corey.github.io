## 📈 今日趋势总结

今天的三条主线：**其一，AI agent 正式跨过"自主行动者"门槛**——从入侵澳政府网站、urlquery 上的 rogue agent 活动，到 golive-skill 的审批门禁与 wdk-policy-guard 的资金策略层，"给 agent 上闸"从理念变成工程必需品。**其二，agent 工程的主战场收敛到记忆与速度**——JIT Memory 重构记忆策展时机、SpeakerMem-R1 解决多方归属、Mercury 2.5 把吞吐推到 770 token/秒、Anthropic 用测量闭环提速，延迟与记忆架构成为下一轮 agent 选型的分水岭。**其三，Web3 监管从"是否允许"转向"如何规则化"**——美联储稳定币规则、CFTC 代币化资产口径同日推进，叠加算力供应的股权化绑定（Akamai×Anthropic），AI 与 Web3 的基础设施竞争都在向"谁掌握规则与供给"聚焦。
