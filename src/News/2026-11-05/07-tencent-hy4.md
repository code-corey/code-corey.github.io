# Tencent Hy4（腾讯混元家族新旗舰 Hy4：卡在成本/精度前沿上的国产重炮）

> 📅 2026-11-04 | 🏷️ 模型发布 & 行业动态 | ⭐ HN 172分/59评论
> 🔗 原文：https://hy.tencent.ai/research/hy4
> 💬 讨论：https://news.ycombinator.com/item?id=50365780

## 是什么

腾讯在混元（Hunyuan）官方研究站（hy.tencent.ai）上线了 Hy4 研究页，这是混元家族的新一代旗舰模型。该发布经 HN 讨论区扩散（172 分），讨论焦点集中在三点：**成本/精度前沿**上的定价策略、与 Kimi/DeepSeek 等国产竞品的对比、以及社区转述的「开放权重后价格还会更低」承诺。第三方评测（Plotly 数据分析基准）称其在成本-精度前沿上表现出色，但行为「非常彻底、非常慢」。

## 🔍 小白解读

### 先说几个词

- **旗舰模型**：厂商技术实力最强的那款模型，通常最先用于对外 API 服务，之后才可能开源。
- **成本/精度前沿（cost-accuracy frontier）**：把各模型画在「价格 vs 答对率」的散点图上，位于左上边界线的模型意味着「同样的钱买到更高的准」或「同样的准花更少的钱」。
- **开放权重（open-weight）**：公开模型参数文件供下载自部署，但训练数据/细节未必公开；开放权重通常伴随 API 降价。
- **每百万 token 定价**：大模型按「token」（约等于半个到一个汉字/英文单词）计费，输入、缓存输入、输出分开报价。
- **agentic 行为**：模型自主拆解任务、多次调用工具/查询完成目标的工作方式。

### 这篇到底在说什么

打个比方：手机圈发新旗舰看跑分，模型圈发新旗舰看「性价比曲线」。腾讯 Hy4 发布后，HN 讨论区里的专业用户迅速给出了实测和账本：有人对比缓存输入/输入/输出三档定价，指出它的输出价格高于 DeepSeek 的高峰时段价（后者约为其一半）；也有高赞评论认为它比同日开放权重的 Kimi 3.1M Pro 性能略逊但**价格便宜不少**，且腾讯承诺开放权重后价格更低——等于把国产模型的价格战直接打到了 API 计费表上。第三方基准（Plotly 数据分析评测）的反馈很有意思：Hy4 为了把题做透，一道题平均跑约 26 次查询、最多 64 次，准确率不错但速度慢，落在两个 GPT-6.1 系列模型之间的成本/精度位置。官方页面也坦承：在研究级数学、长程编码、自我改进和高级视觉问答上与顶级闭源模型仍有差距，将持续扩大预训练与后训练。另外讨论区还提到其视觉与电脑操作演示（大范围卫星图中定位 2 米级目标、照片地理定位）相当抢眼。

### 这跟普通人有什么关系

国内 AI 服务的价格还会继续下探——旗舰级模型互相压价，最终受益的是所有用 AI API 做产品的开发者。对普通用户而言，「便宜但慢而彻底」的模型适合不赶时间的批量任务，赶时间的交互场景仍要选快的。

## 为什么值得架构师关注

- **国产选型矩阵新增一列**：Hy4 提供了「成本敏感 + 精度敏感」场景的新选项，与 DeepSeek（极致低价）、Kimi（开放权重先发）形成差异化三角。
- **定价结构即架构信号**：缓存输入 $0.042 vs 未命中输入 $0.83 的巨大价差（HN 讨论区引用数据）说明该模型强烈鼓励 prompt 缓存设计——应用层的缓存命中率工程将直接影响成本数量级。
- **「彻底但慢」的行为特征要进压测**：多查询 agentic 风格意味着单请求延迟与成本预估都要按「多次工具调用」建模，超时与并发预算需重算。
- **开放权重路线图**：若承诺兑现，私有化部署选型又多一个高水准候选；当前为 API 闭源形态，锁定前先确认条款。
- **对现有架构意味着什么**：不需要立即换模型；建议纳入季度 A/B 评估，重点测成本敏感的长任务批处理场景。

## 核心内容

- 发布载体：腾讯混元官方研究站研究页（hy.tencent.ai/research/hy4），HN 172 分扩散。
- 定价（HN 讨论区引用）：缓存输入 $0.042 / 输入未命中 $0.83 / 输出 $2.50 每百万 token 量级；对比 DeepSeek 高峰 $0.30/$1.20、低谷 $0.15/$0.60。
- 社区评价两极维度：比 Kimi 3.1M Pro 便宜且差距不大（高赞评论）；输出单价高于 DeepSeek，「成本竞争力」存疑（另一高赞评论）。
- 第三方基准：Plotly 数据分析评测称其落在 GPT-6.1 Sol 与 Terra 之间的成本/精度前沿，每题约 26~64 次查询，「非常彻底、非常慢」。
- 官方口径（HN 转述）：与顶级闭源模型在研究级数学、长程编码、自我改进、高级 VQA 上仍有差距；开放权重后价格会更低。

## 行动建议

- 已用国产 API 的团队：把 Hy4 加入 A/B 矩阵，优先测试「缓存友好 + 批量长任务」场景，量化缓存命中率对账单的影响。
- 私有化部署需求方：暂缓决策，标记其开放权重时间表为关键观察点，届时第一时间跑内部基准。
- 所有团队：借该案例把「prompt 缓存策略」提升为成本工程的一级科目。
