# jackwener/DSH-Android: 免 ROOT 在安卓手机上跑 DeepSeek Harness（一个 APK 变身手机智能体）

> 📅 2026-10-27 | 🏷️ 值得研究的仓库 | ⭐ 697 stars（7 天窗口）| 🅺 Kotlin
> 🔗 原文：https://github.com/jackwener/DSH-Android

## 是什么

DSH-Android 让一台普通安卓手机不刷机、不装终端环境，仅通过一个 APK 就运行 DeepSeek Harness（AI 智能体引擎）：引擎内嵌在 App 进程里，能读屏并操作其他 App、修改系统设置、执行定时/条件自动化任务，高级权限场景可选配合 Shizuku。项目上线一周获 697 stars，是本期 7 天爆发窗口中热度最高的国产开发项目之一。

## 🔍 小白解读

### 先说几个词

- **ROOT**：获取安卓系统的最高管理员权限。以前想让一个 App 「管」别的 App，通常得先刷机 ROOT，风险高、还丢保修。
- **Termux**：安卓上著名的终端模拟器 App，过去在手机上跑命令行工具基本都靠它，但对普通用户门槛不低。
- **读屏（无障碍服务）**：安卓提供的官方接口，让 App 能「看见」屏幕上显示的内容并代替用户点击——本是给视障用户设计的，现在成了手机 AI 代理操作界面的标准通道。
- **Shizuku**：一个「权限中介」工具，借用开发调试（adb）级别的权限让普通 App 获得更高操作能力，不用 ROOT。
- **Harness**：「运行外壳」，把模型包装成能持续干活、能调工具的完整系统的那层工程结构。

### 这篇到底在说什么

打个比方：以前的手机 AI 助手像个「遥控器」，只能帮你打开别的 App 或者答个问题；DSH-Android 更像是把一个「打工者」直接塞进了手机里——它自己长在手机上（引擎内嵌 App 进程），看得见屏幕（读屏），点得动按钮（操作 App），能改设置，还会按你定的闹钟和条件自动干活。关键技术亮点是**免 ROOT 免 Termux**：过去干这些事要「拆机」（刷机获取最高权限），现在装个普通 App 就行，门槛从极客级降到小白级。一周 697 star 说明「手机端 agent」的需求真实存在。

### 这跟普通人有什么关系

对普通用户：手机上的重复操作（每天固定打卡、整理截图、批量设置）有了「说一句话就让 AI 替你点」的可能，而且不用折腾刷机。对开发者：这是一个可以研究的端侧 agent 工程样本——怎么在资源受限的手机上跑智能体循环。

## 为什么值得架构师关注

- **端侧 agent 形态参考**：与云端 agent 相比，端侧方案的数据不出设备、无 API 费用，但能力受限于无障碍接口——这两种架构的成本/能力/隐私三角是移动端 AI 选型的核心决策。
- **权限模型的工程教科书**：引擎内嵌 App 进程 + 无障碍服务 + 可选 Shizuku，这是在不 ROOT 前提下能拿到的权限上限方案，移动团队可直接借鉴。
- **风险即卖点**：读屏 + 改系统设置 = 极高权限，企业环境（MDM 管控设备）大概率要禁用此类应用；反过来说，安全团队也应把它纳入「影子 IT」检测特征库。
- **国产项目信号**：DeepSeek 系模型 + 国内开发者在端侧 agent 的工程化速度值得关注，7 天 697 star 的增长曲线可用作需求风向标。

## 核心内容

- 免 ROOT 免 Termux：单 APK 安装即用，引擎运行在 App 自身进程内。
- 能力清单：读屏操作其他 App、修改系统设置、定时/条件自动化触发。
- 高级权限场景可选 Shizuku 作为权限中介。
- Kotlin 实现，⭐697，创建于 2026-10-27，属 7 天爆发窗口（本期仓库类目第 4 名）。
- 名称中的 DSH 指 DeepSeek Harness，即以 DeepSeek 系模型为核心的智能体运行框架。

## 行动建议

① 移动端有自动化需求的团队，可评估其「无障碍服务 + 内嵌引擎」架构是否适用于自家场景，重点测稳定性与耗电；② 使用前务必审计权限边界，禁止在含敏感数据的设备上随意部署；③ 安全团队将其特征加入移动端高权限应用清单；个人用户尝鲜建议用备用机。
