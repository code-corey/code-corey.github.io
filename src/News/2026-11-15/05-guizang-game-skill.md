# 歸藏 Game Skill：让 AI 从零做出能在浏览器里玩的 3D 动作游戏

> 📅 2026-11-15 | 🏷️ 值得研究的仓库 | ⭐ ⭐340（7天）
> 🔗 原文：https://github.com/op7418/guizang-game-skill

## 是什么

歸藏（op7418，国内头部 AI 博主）开源的 Game Skill：一个给 Claude Code / Codex 用的「技能包」，让 AI 从零做出能在浏览器里玩的 3D 动作游戏——包括用 AI 生成美术素材、用 three.js 写成单 HTML 文件，仓库附了可玩演示《雾锁山门》。4 天左右收获 340 星，JavaScript 实现。

## 🔍 小白解读

### 先说几个词

- **Skill（技能包）**：给编程 Agent 预装的一套「作业指导书」——教它在某类任务上按什么流程、什么规范干活，比裸问效果好得多。
- **three.js**：网页里做 3D 画面的最流行开源库，浏览器里的 3D 游戏大多靠它。
- **单 HTML（single-HTML）**：整个游戏打包成一个网页文件，双击就能玩，不用装任何东西。
- **AI 生成素材（AI-generated assets）**：游戏里的贴图、模型、音效等资源不用人画，而是用 AI 生图/生模型工具批量产出。

### 这篇到底在说什么

打个比方：Agent 像一个学徒厨师，手艺有但没菜谱，做出来的东西时好时坏。Skill 就是老师傅手写的标准菜谱——「做 3D 游戏时先立关卡结构、再生成素材、再用 three.js 组装、最后按这些性能规范自查」。作者把自己做游戏的方法论打包成 skill 开源出来，AI 照着做，就能稳定产出一个能玩的《雾锁山门》演示。这件事的看点不在「游戏本身多好玩」，而在示范了一种模式：**领域专家把自己的 know-how 写成 skill，AI 的产出质量就能上一个台阶**。

### 这跟普通人有什么关系

会写提示词的人很多，但把自己领域经验沉淀成 skill 的人还很少。如果你的工作有套路（做报表、写周报、剪视频），把它整理成 skill 喂给编程 Agent，就能得到一个「按你的章法干活」的助手。这个仓库就是一个现成的模仿范本。

## 为什么值得架构师关注

- **Skill 工程化样本**： Claude Code / Codex 的 skill 机制正在成为「领域知识注入 agent」的事实标准之一，这个仓库是中文圈可读性较高的真实案例，适合作为团队内「怎么写 skill」的参考实现。
- **AI 游戏资产管线**：素材生成 + three.js 组装 + 单 HTML 交付的流水线，对做营销小游戏、原型验证的团队有直接复用价值；对游戏行业则是「小体量游戏生产成本趋近于零」的又一信号。
- **增长质量**：作者社区影响力大（op7418 为知名中文 AI KOL），340 星/4 天的增速有真实社区讨论支撑，非刷量特征。
