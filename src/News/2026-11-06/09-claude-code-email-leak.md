# Claude Code sends your email address to websites（Claude Code 会把你的邮箱地址发给所访问的网站）

> 📅 2026-11-05 | 🏷️ 安全 & 评测 | ⭐ HN 355分/115评论
> 🔗 原文：https://github.com/anthropics/claude-code/issues/107757

## 是什么
有开发者向 Anthropic 官方仓库提交 issue（#107757），指出 **Claude Code 在访问网站时会把用户的邮箱地址一并发送出去**。该 issue 经 HN 传播后迅速获得 355 分、115 条评论。这是「编码 Agent 出站流量会携带用户身份」这一问题首次以一手 GitHub 证据大规模进入公众视野。

## 🔍 小白解读

### 先说几个词
- **Claude Code**：Anthropic 的命令行编码 Agent，能读写你的代码库、联网查资料、执行命令。
- **出站请求（Egress）**：工具主动向外部网络发出的访问。Agent 干活时要频繁上网，每一次出站都是一次数据暴露面。
- **身份泄露（Identity Leak）**：请求里夹带了能唯一定位你的信息（如邮箱），对方网站由此知道「是谁在访问我」。
- **隐私默认（Privacy by Default）**：产品默认行为应当最小化数据外发，而不是依赖用户自行发现并关闭。
- **供应链信任**：你信任的官方工具，其每一个隐蔽行为都会被成千上万家企业继承。

### 这篇到底在说什么
打个比方：你请了一位助理帮你跑腿取资料，后来发现他每次敲门都先自报你家门牌——不管你要不要。Claude Code 是无数开发者每天用来访问开源仓库、技术文档、API 站点的工具，若每次出站都带上邮箱，意味着用户的访问足迹被精准标注：谁在调研哪个项目、哪家公司在评估什么技术。这类信息对竞品分析、定向营销甚至定向攻击都有价值。值得强调的是：问题机制与影响范围以 issue 正文和 Anthropic 官方响应为准，但 HN 的热度说明社区对「Agent 默认外发身份信息」的容忍度极低——大家对终端工具的隐私预期，正在向浏览器「禁止静默跟踪」看齐。

### 这跟普通人有什么关系
如果你用 AI 编程工具，你的邮箱可能正在替你「实名上网」；如果你是企业员工，个人身份与公司调研行为可能被第三方关联。即使不用编程工具，这也是一个普遍信号：AI 工具的默认网络行为需要像审查 App 权限一样被审查。

## 为什么值得架构师关注
三个动作点：**盘点**——梳理团队在用编码 Agent 的出站路径（代理、防火墙日志），验证是否存在同类身份信息外发；**管控**——Agent 的网络出口应收敛到审计代理，对其 User-Agent、请求头做白名单与脱敏；**流程**——把「出站流量审查」加入 AI 工具准入评审清单，新工具上线前用抓包验证默认行为。该事件同时提醒：官方工具 ≠ 隐私安全，供应商行为需要技术验证而非合同信任。

## 核心内容
- 一手证据：anthropics/claude-code 仓库 issue #107757，直指 Claude Code 向其访问的网站发送用户邮箱地址。
- HN 355 分/115 评论（2026-11-05），社区对 Agent 隐私默认强烈关注。
- 影响面：Claude Code 是主流编码 Agent 之一，同类「出站携带身份」问题值得对所有 Agent 工具做举一反三排查。
- 具体触发机制与修复进展以 issue 正文及 Anthropic 官方响应为准。

## 行动建议
本周内：对团队在用的所有编码 Agent 执行一次出站抓包/代理日志审计，确认是否有身份信息（邮箱、账号 ID）外发；为 Agent 网络出口启用统一代理与请求头审查；跟进该 issue 的官方修复并在版本升级后复验。
