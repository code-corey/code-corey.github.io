# poki — Let AI agents operate a real iPhone（让 AI 智能体操控真实 iPhone）

> 📅 2026-11-06 | 🏷️ 值得研究的仓库 | ⭐ ⭐192（1 天，7 天窗口，JavaScript）
> 🔗 原文：https://github.com/JosssphZhou/poki

## 是什么
一个让 AI 智能体直接操作真实 iPhone 的开源项目：本地运行的 MCP 服务器加配套 Agent，免越狱（no jailbreak）、免额外硬件。2026-11-05 创建，一天内冲到 192 星，是移动端设备操控 Agent 方向最新晋的热门实现。

## 🔍 小白解读

### 先说几个词
- **MCP（Model Context Protocol）**：模型连接外部工具的统一标准接口，此处把「一台 iPhone」封装成了 Agent 可以调用的工具。
- **越狱（Jailbreak）**：破解 iOS 系统限制以获得完全控制权——会失去保修与安全更新；「免越狱」意味着手机保持官方系统状态。
- **设备操控 Agent**：能看屏幕、点按钮、输文字、执行任务的 AI，相当于一个住进手机里的远程助手。
- **本地服务（Local Server）**：程序跑在你自己的电脑上而不是云端，数据不经过第三方服务器。

### 这篇到底在说什么
打个比方：以前的手机自动化像「按键精灵」，只会按录制好的固定剧本操作；poki 这类项目则是给手机装上一个「会理解的实习生」——AI 能看懂屏幕上的内容，自己决定下一步点哪里、输入什么，遇到弹窗和异常也能随机应变。它强调两个卖点：一是免越狱，手机保持官方系统完整性，风险和门槛都低；二是全本地，不需要把屏幕数据上传云端，也不需要额外买硬件。这个方向近半年明显升温：iOS 和安卓的「Agent 操控」都在从极客玩具走向可用工具。

### 这跟普通人有什么关系
对普通用户，这类工具意味着可以授权 AI 帮你完成手机上的重复操作——批量整理、定时任务、应用内巡检——但也要清楚：能操控你手机的 Agent 同样能误触、误删，授权范围需要谨慎。对开发者，这是一个新平台能力的早期信号：当智能体可以原生操作移动设备，App 的交互设计目标将从「给人看」扩展到「给 Agent 用」。

## 为什么值得架构师关注
移动端是被 Agent 化改造最慢的终端，poki 用「本地 MCP + 免越狱」路线降低了集成门槛，值得评估其实现边界（可操控范围、稳定性、与 W3C/各厂商自动化协议的关系）。若业务有移动端自动化测试、RPA、客服陪跑等场景，这条路线可能替代部分昂贵的真机云测方案。风险点：权限模型、隐私边界（屏幕内容是否出本机）与 iOS 版本兼容性需要实测验证。

## 核心内容
- 让 AI Agent 操控真实 iPhone：本地 MCP 服务器 + Agent，免越狱、免额外硬件。
- 2026-11-05 创建，1 天 192 星（7 天窗口），JavaScript 实现。
- 代表移动端 Agent 操控方向的工程化趋势：低门槛（免越狱）+ 本地化（数据不出本机）。
- 与桌面对应物（computer use 类智能体）形成互补，把 Agent 的可达范围延伸到移动 App。

## 行动建议
有移动自动化测试或 RPA 需求的团队可 clone 试用，重点验证：可操控的 App 范围、操作成功率与稳定性、隐私边界；同时关注其权限申请方式是否合规。普通用户建议等生态成熟后再上手。
