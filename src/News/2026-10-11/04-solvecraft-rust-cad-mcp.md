# Solvecraft — Clean-room Fusion 360 Reimplementation in Rust（纯 Rust 重写的开源参数化 CAD）

> 📅 2026-10-11 | 🏷️ 值得研究的仓库 | ⭐ 130 星（7 天窗口，2026-10-07 创建）
> 🔗 原文：https://github.com/bherbruck/solvecraft

## 是什么

Solvecraft 是一个雄心很大的开源项目：以 clean-room 方式、用纯 Rust 重新实现 Autodesk Fusion 360 的核心能力，做一个跨桌面、浏览器、**AI Agent** 三端的参数化 3D CAD。它最独特的一点是通过 MCP（Model Context Protocol）把 CAD 能力直接暴露给 AI Agent——让 AI 不只是"帮工程师写脚本"，而是能直接操作建模工具。2026-10-07 创建，7 天 130 星。

## 🔍 小白解读

### 先说几个词

- **CAD（计算机辅助设计）**：工程师画零件、建模、出图纸用的专业软件，Fusion 360、SolidWorks 都是这类。盖楼、造车、做手机壳都从 CAD 开始。
- **参数化建模**：不是一笔一笔画死，而是用"尺寸和关系"来定义模型——改一个参数（比如孔的直径），整个模型自动跟着变。像 Excel 公式：改一个格子，结果全联动。
- **Clean-room 重写（净室开发）**：不看原代码、只按公开行为从头写一个功能相同的实现，避免版权问题。像"照着菜谱做菜"而不是"偷师后厨"。
- **Rust**：一门以内存安全和性能著称的编程语言，近年系统软件重写的首选。
- **MCP（Model Context Protocol）**：AI 模型连接外部工具的"USB-C 接口"标准，让 AI Agent 能标准化地调用软件能力。

### 这篇到底在说什么

专业 CAD 软件长期被少数商业巨头垄断，一个 Fusion 360 订阅不便宜，而且它们从来不是为 AI 准备的。Solvecraft 干了两件事：第一，用 Rust 从头写一个开源的参数化 CAD，桌面、浏览器都能跑；第二，给这个 CAD 装上 MCP 接口，让 AI Agent 能直接"上手"建模——你说"给我一个带散热孔的外壳"，AI 可以在 CAD 里实际操作参数完成建模，而不只是给你一段代码。打个比方：以前的 CAD 是只有老司机能开的手动挡卡车，Solvecraft 相当于给卡车装上了"AI 自动驾驶接口"。7 天 130 星，对一个如此硬核的方向来说是非常快的起点。

### 这跟普通人有什么关系

如果你有 DIY、3D 打印、小产品定制需求，未来可能用"说一句话就出模型"的工具，而背后正是这类"AI 原生 CAD"。对机械、硬件行业的从业者，开源 CAD + AI 操作意味着专业工具的使用门槛和订阅成本都可能被拉低。

## 为什么值得架构师关注

- **"专业软件 × MCP"的样板**：把重型桌面软件的领域能力通过 MCP 暴露给 Agent，是 Agent 生态从"文件/浏览器工具"走向"行业软件"的关键一步，任何拥有专业软件资产的公司都值得对照思考自己的 MCP 暴露层。
- **Rust 重写桌面级软件**：几何内核是出了名的难（数值稳定性、边界情况爆炸），clean-room + Rust 的组合在许可证安全性与内存安全上都是教科书级选择，可跟踪其工程路线。
- **三端同构**（desktop/browser/agent）：一套内核服务三类宿主，架构上值得研究其抽象层怎么切。
- **选型视角**：若团队有 CAD/EDA 类工具链国产化或开源化诉求，这是极少数可跟踪的早期项目。

## 核心内容

- 开源 clean-room 重实现 Autodesk Fusion 360，纯 Rust 编写，规避商业许可风险。
- 参数化 3D CAD，同时面向桌面、浏览器与 AI Agent 三类使用端。
- 通过 MCP 服务器暴露 CAD 能力，AI Agent 可直接驱动建模操作。
- 2026-10-07 创建，7 天 130 星（Rust），处于极早期但增速显著。
