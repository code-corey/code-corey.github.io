# dots: An AI agent with its own browser, one that does not get blocked（dots：自带浏览器且不被封禁的 AI Agent）

> 📅 2026-09-29 | 🏷️ 值得研究的仓库 | ⭐ ⭐1933（7天爆发：09-29 创建，两日冲榜）
> 🔗 原文：https://github.com/feder-cr/dots

## 是什么

feder-cr/dots 是一个 Python 开源项目，自我定位非常直白：「Open-source dots for the web」——给 AI Agent 配一个专属浏览器，而且这个浏览器「不会被封禁（does not get blocked）」。项目于 09-29 创建，两天内冲到 1933 星，是本周 GitHub AI 类目爆发的第一名。

> ⚠️ 名称澄清：本项目与昨日报道的 OpenAI 官方产品「Dots: Always-on agents」同名，为社区同名/呼应项目，二者关系未证实，主打点完全不同（OpenAI Dots 是常驻智能体产品，本项目是反封锁浏览器自动化）。

## 🔍 小白解读

### 先说几个词

- **反爬/风控（Anti-bot）**：网站用来识别并拦截自动化程序的技术，比如验证码、行为分析、指纹检测。好比小区门禁，认脸不放行陌生人。
- **浏览器指纹（Fingerprint）**：浏览器暴露的一堆特征（字体、分辨率、行为节奏）组合成的「身份证」，风控系统靠它分辨真人和脚本。
- **Agent + 浏览器**：让 AI 操控浏览器替你干活——查价格、填表单、抢票、比价。浏览器是 Agent 触达真实互联网的手。
- **Stars（星标）**：GitHub 上的「收藏」数字，两天 1933 星意味着每天近千人收藏，属于病毒级传播。

### 这篇到底在说什么

AI Agent 要替人干活，绕不开浏览器——订机票、查资料、操作后台，都得像人一样点网页。但绝大多数网站不喜欢机器人来访，会用工夫封禁。dots 这个项目就在解决一个问题：让 Agent 的浏览器访问「看起来像真人」，不被反爬系统拦下来。它两天拿下 1933 星，说明「Agent 上网被拦」是大量开发者的真实痛点。但这里有一枚硬币的两面：对开发者，这是自动化自由的工具；对网站方，这是一场不对等的攻防——反爬系统本来就是网站保护自己数据和服务能力的方式。项目爆火本身也是个信号：Agent 与 Web 的关系正在从「 API 优先」滑向「浏览器优先」，因为大多数网站不会为 Agent 开 API。

### 这跟普通人有什么关系

如果你用 AI 助手订票、比价、整理信息，这类技术决定了它能不能真的帮你跑腿。但也要注意：用它去操作有明确服务条款限制的网站（比如抢票、批量注册）可能违反平台规则甚至法律，工具是中性的，用法不是。

## 为什么值得架构师关注

- **反爬攻防是 Agent 落地的隐藏成本项**：任何需要 Agent 访问第三方网站的产品，都要把「被封禁率」当成核心可靠性指标，dots 的方案值得作为对照组评估。
- **合规红线必须前置**：绕过风控可能违反目标网站服务条款，特定司法辖区还可能触及计算机滥用法；商用前必须过法务，这一点比技术评估更优先。
- **技术路线的参考价值**：即使不用本项目，「Agent 专用浏览器」的指纹管理、行为模拟、会话隔离等设计，对自研浏览器自动化也有直接借鉴意义。
- **增速解读**：两日 1933 星的爆发速度本身是市场信号——「Agent 访问 Web 受阻」是被低估的普遍痛点，产品规划中应预留相应工时。

## 核心内容

- 仓库：github.com/feder-cr/dots，Python 项目，2026-09-29 创建。
- 定位：开源的 Web Agent 专用浏览器，核心卖点是「不被封禁」。
- 热度：7 天爆发窗口内 1933 星（两日达成），为本期 gh.json 爆发榜第一名。
- 与 OpenAI 官方产品 Dots 同名但定位不同（见文首澄清），阅读社区讨论时注意检索混淆。
- 反封锁的具体技术手段（指纹策略、代理方案等）以仓库文档为准，本刊不作二手转述。

## 行动建议

- 做 Agent 产品的团队：先用「合规访客」场景评估——只自动化你有权访问的目标，把 dots 当浏览器自动化的工程参考。
- 评估时必看三件事：指纹模拟的实现深度、会话与代理管理能力、维护活跃度（反封锁是持续军备赛，停更即失效）。
- 法务与合规部门应提前介入评估使用边界；不涉及 Web 自动化的团队：了解即可。
