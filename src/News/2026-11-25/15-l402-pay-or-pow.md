# Pay or PoW: Lightning (L402) paywall and anti-DDoS shield（spikes402：让 AI 爬虫付聪或算力换内容访问）

> 📅 2026-11-25 | 🏷️ Web3 & Crypto | ⭐ 2（早期仓库，选题稀缺，2026-11-20 创建）
> 🔗 原文：https://github.com/Choffolo/spikes402

## 是什么

spikes402 是一个 Go 编写的开源组件：基于 Lightning 网络的 L402 协议构建付费墙与反 DDoS 盾——AI 机器人和爬虫想抓取受保护内容，要么支付聪（比特币最小单位），要么提交工作量证明（PoW）。仓库极早期（⭐2），但选题恰好踩中"AI 爬虫 vs 内容方"的全球性矛盾，入选本期 Web3 仓库观察（依据「问题极其独特」豁免条款）。

## 🔍 小白解读

### 先说几个词

- **L402（原 LSAT）**：Lightning Labs 提出的付费访问协议，借用 HTTP 402 状态码（"Payment Required"）——服务器先回一张"价签"（宏令牌），客户端用闪电网络付钱后换取访问凭证。
- **聪（satoshi/sat）**：比特币的最小单位（1 亿分之 1 BTC），适合机器间的微支付，一次抓取付几聪毫无痛感。
- **工作量证明（PoW）**：让请求方先做一道耗算力的数学题再放行——人类点一下网页没事，爬虫每秒抓万次就会被算力成本拖垮。
- **Pay or PoW（付钱或干活）**：二选一的准入策略，把"免费滥用"变成"要么花钱、要么花算力"。

### 这篇到底在说什么

打个比方：你的网站像一家免费开放的图书馆，AI 公司派了几千个机器人每天来复印整馆书籍还不打招呼。spikes402 相当于在门口装了个智能闸机：机器人要么投币（闪电网络微支付）进馆，要么当场做套体力活（PoW）证明自己不是来扫货的。这正是 Cloudflare 等巨头推"Pay per Crawl"付费爬取的同一命题的开源化、去中心化版本——用比特币闪电网络做结算通道，不依赖任何一家中间商。当然，2 星的极早期仓库意味着它目前更多是概念验证，生产可用性（性能、误伤真人用户、支付体验）尚未验证。

### 这跟普通人有什么关系

内容创作者（博主、媒体、数据站主）未来可能多一种收入模式：AI 想学你的内容，请先付费；普通用户几乎无感——真人浏览通常免费放行。

## 为什么值得架构师关注

1）**Agent 经济的计费原语**：L402 是"机器对机器按次付费"的最小可用协议，若 Agent 自主调用第三方 API/内容成为常态，402+微支付的架构模式值得纳入 API 网关设计预研；2）**反爬策略演进**：从 robots.txt（君子协定）到付费爬取（经济手段），内容方 API 架构需要新增计费与 PoW 中间件层；3）**成本核算**：PoW 防护的算力成本转嫁模型（真请求延迟 vs 爬虫成本）需要实测，别照搬参数。

## 核心内容

- 仓库：Choffolo/spikes402（Go），实现 L402 付费墙 + 反 DDoS，双策略为「支付聪或提交 PoW」。
- 协议基础：Lightning L402（HTTP 402 + 闪电网络宏令牌），机器微支付的标准协议路线。
- 语境：与 Cloudflare Pay per Crawl 等商业方案同命题，本仓库是其开源去中心化版本。
- 状态：⭐2、创建于 2026-11-20，属概念验证阶段（本期唯一入选的早期仓库，依据选题稀缺性豁免）。
