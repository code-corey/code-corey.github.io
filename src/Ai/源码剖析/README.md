# 源码剖析 · Agent 实战框架

本分组收录 Agent 实战框架的源码阅读系列，三套代码对应 agent 工程的三种典型形态：

- **[DeepSeek Harness 源码](deepseek-harness/)**（9 篇，完本）—— DeepSeek 开源的 agent harness 底座，副标题「Everything is a Plugin」，平台级插件化架构（TypeScript）。
- **[Hermes Agent 源码](hermes-agent/)**（6 篇）—— NousResearch 的「越用越懂你」个人 agent 产品：从经验中创建技能、跨会话记住用户（Python）。
- **[Pi Web 源码](pi-web/)**（8 篇，完本）—— pi coding agent 的官方生态 Web UI：进程内 SDK 集成、SSE 事件流与 608 个提交里的渐进式长成（TypeScript）。

三者的对照与取舍在各自系列的收尾篇中有横向比较，建议先读 DeepSeek Harness 打底，再看 Hermes 与 Pi Web 两种产品化路线。
